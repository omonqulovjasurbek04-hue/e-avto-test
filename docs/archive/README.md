# Arxiv: rejalar va AI promptlar

Bu papkadagi hujjatlar **amaldagi holatni tasvirlamaydi**. Ular loyiha boshida yoki kengaytirish uchun yozilgan
rejalar va AI vositalariga beriladigan promptlardir. Ayrimlari kodda yo'q imkoniyatlarni (Next.js, to'lovlar,
o'qituvchi/davomat tizimi, private media, 2FA) tasvirlaydi.

Amaldagi holat uchun: [../README.md](../README.md), [../api.md](../api.md), [../database.md](../database.md),
[../TASKS.md](../TASKS.md), [../telegram.md](../telegram.md).
